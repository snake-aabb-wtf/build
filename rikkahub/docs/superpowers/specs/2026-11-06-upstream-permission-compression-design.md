## 做法与取舍

采用小范围移植，复用现有 Compose 组件、权限框架和压缩服务。

原样移植压缩输入会保留空值回退为 0、手动输入和加减按钮上限不一致的问题，不满足本次边界要求。仅校验整数、提交后再由服务拒绝过大保留数虽然改动更少，但调用方已有当前会话，可以在弹窗内提前说明有效范围。因此设计采用输入校验及会话范围校验，并保留服务的最终检查。

不进行整段上游同步，以便分别审查、验证和回退这两项改动。用户已确认本设计中的具体输入规则。

## 局域网权限提示

- 按上游行为，在 Android API 37 及以上且本地网络权限未授予时，在主设置页顶部显示说明卡片。
- 由用户点击卡片发起现有权限请求；不在进入设置时自动弹出系统授权框。
- 复用现有拒绝说明、永久拒绝后的系统设置入口及生命周期恢复时的权限状态刷新。
- 授权后卡片消失；低于 API 37 的设备不显示，也不访问新权限 API。
- 权限说明覆盖连接局域网自建服务和其他设备访问内嵌 Web 服务器两种用途，沿用上游对现有八套语言资源的更新。
- 不改变 Web 服务器原有权限请求及启动流程，也不增加请求失败后自动重试。

## 压缩保留数输入

沿用现有压缩弹窗、额外提示词、默认保留数 0 和两侧加减按钮；中间数字改为可编辑输入，提供数字键盘、可访问标签和就地错误说明。

| 情况 | 约定行为 |
| --- | --- |
| 默认值或明确输入 0 | 有可压缩消息时允许确认；说明 0 表示本次范围内的全部消息参与压缩，原始历史仍保留 |
| 合法整数 | 允许输入或粘贴，传递准确的保留数 |
| 全角数字、前导零及前后空白 | 全角数字转为半角，前后空白可忽略，前导零不改变数值；不因先截断而把 000012 误变成 0 |
| 空输入 | 允许编辑时暂时为空，提示填写数值，禁止确认；不回退为 0 |
| 负数、小数、混杂文本 | 显示输入错误并禁止确认；不删除其中字符后拼成另一个有效数值 |
| 超过整数范围的超长数字 | 显示输入错误并禁止确认，无溢出、截断或回退 |
| 大于当前可保留上限 | 显示允许范围并禁止确认；不默默改成上限 |
| 加减按钮 | 仅在输入有效且对应方向仍有空间时启用，与手动输入使用相同范围；不会越界或溢出 |

范围按当前会话选中的消息节点计算，和现有服务含义一致：

- 设最后一个当前选中消息为压缩检查点的节点之后，共有 N 个节点；没有检查点时使用全部节点。
- N 大于 0 时，可保留范围为 0 到 N−1，至少留下一个节点参与压缩。
- N 为 0 时，说明当前没有可压缩消息，禁止确认。
- 会话状态变化使输入超范围时，重新显示错误，不自动替用户改值。
- 由已经持有 Conversation 的 FilesPicker 传入范围，压缩服务继续使用最新内存会话和现有检查，不以 UI 快照替换会话。
- 保持现有执行中状态、取消生成和压缩检查点写入行为；不新增跨次打开弹窗的数值记忆。
